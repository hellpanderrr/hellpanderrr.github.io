About This Tool

This Icelandic transcription app uses the Wiktionary Icelandic Pronunciation Module to generate phonemic transcriptions for Icelandic text. IPA (International Phonetic Alphabet) is a standardized system for transcribing speech sounds using symbols based on the Latin alphabet. This tool converts Icelandic orthography (spelling) into IPA, helping learners, linguists, and developers understand pronunciation.

The system uses a comprehensive Wiktionary data dump[1] as a lexicon (the file is_lexicon.zip, decompressed in your browser and cached in IndexedDB) to first retrieve transcriptions from the dictionary. If the word is found, the dictionary IPA is shown exactly as Wiktionary has it. When a word is not found in the lexicon, the app falls back to the pronunciation module's rule-based approach, which is what most of this page describes. The lexicon is used by default; opening the converter with ?dict=false in the address turns it off.

Lexicon vs. rules. Dictionary entries are written by Wiktionary editors, so they can contain irregular pronunciations that no spelling rule could predict (for example loanwords, names, and compounds). The rule path is a deterministic spelling-to-sound converter: the same spelling always gives the same IPA, and it can be wrong whenever Icelandic pronunciation depends on morphology or etymology that spelling does not show. All IPA examples on this page were produced by the rule path only (the test tool that generated them does not load the lexicon), so a word you type into the app may show a different, dictionary-based transcription.

Dialects & Limitations

  • Supported: One standard variety (style "Default"). The rules produce, for example, hv as /kʰv/ and ll as /tl̥/ in every word.
  • Not supported: Regional variants. The module has no switch for other pronunciations of the same spelling (such as a northern hv), and no option for fast-speech reductions.
  • Edge cases: Compounds written as one word, loanwords, and proper names that follow non-Icelandic spelling may not be transcribed correctly (see Common Issues).
  • Technical limit: The module has no dictionary of exceptions and no morphological analysis. It only sees letters.

Phonemic vs Phonetic

  • Phonemic (the only form offered for Icelandic): Uses the Wiktionary lexicon when the word is listed, falls back to the rules otherwise. Although it is labelled "phonemic", the rule output already contains some detail that is predictable from spelling, such as preaspiration (/h/ before a stop) and voiceless sonorants (/n̥/).
  • Phonetic: Not available for Icelandic. The module has a single output with no allophonic second pass.

Quick Reference (Glossary)

Phoneme
The smallest unit of sound in a language that distinguishes meaning (e.g., /p/ vs. /b/ in English "pat" vs. "bat").
Allophone
A variant pronunciation of a phoneme that doesn't change meaning (e.g., aspirated [pʰ] vs. unaspirated [p]).
Digraph / Trigraph
Two (or three) letters that together stand for one sound or sound sequence, e.g., hj /ˈçau̯ː/ or fnt jafnt /ˈjam̥t/.
Diphthong
A gliding vowel sound where the tongue changes position during articulation. Icelandic writes most of them with a single letter, e.g., á sál /ˈsau̯ːl/, ó sól /ˈsou̯ːl/, æ sæti /ˈsai̯ːtɪ/.
Nonsyllabic mark
The inverted breve below /i̯/, /u̯/, /y̯/ marks the second part of a diphthong as a glide (it is not a separate syllable).
Length mark
The triangular colon /ː/ marks a long vowel or a long consonant, e.g., hús /ˈhuːs/ (long) vs hundur /ˈhʏntʏr/ (short).
Aspiration
A puff of air after a voiceless stop, written /ʰ/. In this module only word-initial p, t, k are aspirated, e.g., pípa /ˈpʰiːpa/, tala /ˈtʰaːla/, kaka /ˈkʰaːka/.
Preaspiration
A breathy /h/ before a stop. Icelandic has it in spellings like pp, tt, kk, e.g., hoppa /ˈhɔhpa/, þetta /ˈθɛhta/, bakki /ˈpahcɪ/.
Pre-stopping
Insertion of a brief stop before a long l or n: ll becomes /tl̥/, e.g., kalla /ˈkʰatl̥a/; nn after a stressed vowel becomes /tn̥/, e.g., steinn /ˈstɛi̯tn̥/.
Voiceless sonorant
An l, n, r, m pronounced without voicing, marked with the ring below /l̥/, /n̥/, /r̥/, /m̥/, e.g., hlaupa /ˈl̥œy̯ːpa/, hnífur /ˈn̥iːvʏr/, hringur /ˈr̥iŋkʏr/.
Palatalization
Fronting of k/g to the palatal stop /c/ before front vowels, e.g., kyn /ˈcʰɪːn/, gera /ˈcɛːra/.
Geminate
A doubled consonant. For most letters the module turns a double into one long consonant, e.g., kaffi /ˈkʰafːɪ/.
Compound
A word made of several components. The module only knows a component boundary if you type a hyphen between the parts, e.g., bóka-búð /ˈpou̯ːkaˌpuːð/.
Primary / Secondary stress
Icelandic stress is almost always on the first syllable of each component. The module writes /ˈ/ before the first component and /ˌ/ before later ones.
Lexicon
The dictionary of known words with human-written IPA, tried before the rules.

Interactive Features

  • Click words to cycle variants: Only applies if a word has several stored transcriptions. Click any transcribed word to see alternative IPA forms if available.
  • Audio playback: Click the speaker icon next to any word or line to hear text-to-speech pronunciation (requires browser TTS support and an Icelandic voice).
  • Export results: Use PDF or CSV buttons to save transcriptions in your preferred format.

Multiple Pronunciation Variants

For Icelandic, the rule path returns exactly one transcription per word. Where variants exist they come from the lexicon:

  • Lexicon vs. generated: Dictionary lookup and rule-based generation may produce different results for the same word, because the dictionary reflects what editors wrote.
  • Homographs: Words spelled the same but pronounced differently can only be distinguished by the lexicon, never by the rules.

Icelandic Pronunciation Guide

This guide explains the pronunciation rules that the engine actually implements. Icelandic spelling is fairly regular, but stress, vowel length, and consonant clusters interact in ways that are worth knowing before reading the IPA. Every rule here corresponds to a rule in the Lua module (see Implementation Details).

Vowel Length & Quality

Only the stressed vowel (the first vowel of each component) gets a length decision. All other vowels are written short.

Long Vowels

The stressed vowel is long when the letters after it are:

  • Nothing, or a single letter: Word-final or followed by one last letter. Examples: þú /ˈθuː/, hús /ˈhuːs/, þrír /ˈθriːr/
  • One consonant followed by a vowel: Examples: tala /ˈtʰaːla/, vinur /ˈvɪːnʏr/, kona /ˈkʰɔːna/
  • A stop or s plus j, r or v: The clusters b/d/g/k/p/s/t + j/r/v do not shorten the vowel. Examples: Petra /ˈpʰɛːtra/, tvisvar /ˈtʰvɪːsvar/, sækja /ˈsai̯ːca/

Short Vowels

  • Before two consonants: Examples: vatn /ˈvahtn̥/, mynd /ˈmɪnt/, hestur /ˈhɛstʏr/, allt /ˈatl̥t/
  • Before x: The letter x counts as two consonants. Examples: vax /ˈvaxs/, sex /ˈsɛxs/, box /ˈpɔxs/
  • Before a consonant and a hyphen: The lookahead sees the consonant followed by a hyphen, which is not a vowel, so the vowel stays short (see Common Issues). Example: sjón-varp /ˈsjou̯nvarp/
  • Unstressed syllables: Examples: tala /ˈtʰaːla/ (final /a/), fiskur /ˈfɪskʏr/ (final /ʏr/)

Icelandic Diphthongs

Diphthongs come from three sources: the digraphs au and ei/ey, the single letters á, ó, æ, é, and the context rules for gi and ng/nk.

Spelling IPA Example
au /œy̯/ haus /ˈhœy̯ːs/, auga /ˈœy̯ːɣa/
ei, ey /ɛi̯/ heim /ˈhɛi̯ːm/, eyra /ˈɛi̯ːra/
á /au̯/ sál /ˈsau̯ːl/, á /ˈau̯ː/
ó /ou̯/ sól /ˈsou̯ːl/, ó /ˈou̯ː/
æ /ai̯/ sæti /ˈsai̯ːtɪ/, gæs /ˈcai̯ːs/
é /jɛ/ Pétur /ˈpʰjɛːtʏr/, ég /ˈjɛːk/

Because the digraph au is matched before single letters, a word like haus /ˈhœy̯ːs/ gets one diphthong rather than a followed by u. The letter y is respelled to i before any of this happens, so ey is simply ei, e.g., keyra /ˈcʰɛi̯ːra/.

Stress and Compounds

The engine puts primary stress /ˈ/ on the first syllable of the word. It knows nothing about prefixes, suffixes, or compounds unless you type a hyphen:

  • One word, one stress: bókabúð /ˈpou̯ːkapuð/ gets a single stress, so the second component is treated as an unstressed ending (short vowel, no secondary stress).
  • With hyphens: bóka-búð /ˈpou̯ːkaˌpuːð/. Each hyphen starts a new component. The first gets /ˈ/, later ones get /ˌ/, and the first vowel of each component is treated as stressed (length rules apply to it).
  • Secondary stress dropped: If both the part before and the part after a /ˌ/ contain only one syllable, the secondary stress is removed. Compare fót-bolti /ˈfou̯tˌpɔltɪ/ (kept) with sjón-varp /ˈsjou̯nvarp/ (dropped).
  • Hyphens reset the "initial" state: After a hyphen, aspirated initial forms are used again: kaffi-hús /ˈkʰafːɪˌhuːs/.

Aspiration (p, t, k)

Only p, t, k at the start of a word (or right after a hyphen) are aspirated. The letters b, d, g always give unaspirated /p/, /t/, /k/:

  • pípa /ˈpʰiːpa/, tala /ˈtʰaːla/, kaka /ˈkʰaːka/: aspirated
  • bók /ˈpou̯ːk/, daginn /ˈtai̯cɪnː/, gata /ˈkaːta/: from b, d, g
  • api /ˈaːpɪ/, taka /ˈtʰaːka/, skip /ˈscɪːp/: not word-initial, so not aspirated

Preaspiration (pp, tt, kk, pl, tn ...)

Double stops and stop + l/m/n clusters get a preceding /h/. If an l, m, n follows, it is voiceless:

Spelling IPA Example
pp, tt, kk /hp/, /ht/, /hk/ hoppa /ˈhɔhpa/, þetta /ˈθɛhta/, bakki /ˈpahcɪ/
pl, tl, kl /hpl̥/, /htl̥/, /hkl̥/ epli /ˈɛhpl̥ɪ/, ætla /ˈai̯htl̥a/, Hekla /ˈhɛhkl̥a/
pm, tm, km /hpm̥/, /htm̥/, /hkm̥/ Kaupmanna-höfn /ˈkʰœy̯hpm̥anːaˌhœvn/ (pm; no common example for tm, km)
pn, tn, kn /hpn̥/, /htn̥/, /hkn̥/ vopn /ˈvɔhpn̥/, vatn /ˈvahtn̥/, sakna /ˈsahkn̥a/

Pre-stopping (ll, nn, rl, rn, sl, sn)

  • ll always becomes /tl̥/: kalla /ˈkʰatl̥a/, ull /ˈʏtl̥/, fjall /ˈfjatl̥/
  • rl, rn become /rtl̥/ and /rtn̥/: perla /ˈpʰɛrtl̥a/, barn /ˈpartn̥/
  • sl, sn become /stl̥/ and /stn̥/: slá /ˈstl̥au̯ː/, snúa /ˈstn̥uːa/, íslenska /ˈistl̥ɛnska/
  • nn becomes /tn̥/ only straight after a stressed syllable (the stress mark, optional consonants, and one vowel): steinn /ˈstɛi̯tn̥/, hinn /ˈhɪtn̥/, rennur /ˈrɛtn̥ʏr/. In later positions it becomes a long consonant: kominn /ˈkʰɔːmɪnː/

Voiceless Sonorants (hl, hn, hr)

The digraphs hl, hn, hr become voiceless /l̥/, /n̥/, /r̥/: hlaupa /ˈl̥œy̯ːpa/, hnífur /ˈn̥iːvʏr/, hringur /ˈr̥iŋkʏr/. The module does not devoice a plain l, n, r before a voiceless consonant on its own; only the spellings listed in this guide produce voiceless sonorants. For example kalt /ˈkʰalt/ and hjálp /ˈçau̯lp/ keep a voiced /l/.

Palatal Consonants (k, g, kj, gj, hj)

  • k/g before a front vowel (/ɛ/, /i/, /ɪ/, /ai/) become /c/ (/cʰ/ when aspirated): kyn /ˈcʰɪːn/, gera /ˈcɛːra/, gæs /ˈcai̯ːs/, ekki /ˈɛhcɪ/
  • kj is /cʰ/ at the start of a word, otherwise /c/: kjöt /ˈcʰœːt/, skjól /ˈscou̯ːl/, tekkja /ˈtʰɛhca/
  • gj is /c/ at the start of a word: gjöf /ˈcœːv/, gjá /ˈcau̯ː/. Elsewhere it stays as g + j until the later rules: segja /ˈsɛi̯ːja/
  • hj is /ç/: hjá /ˈçau̯ː/, hjól /ˈçou̯ːl/

Fricatives (g, f, ð, þ, x)

g

  • After a vowel, before a, u, ð, l, r: /ɣ/: dagar /ˈtaːɣar/, dagur /ˈtaːɣʏr/, sagði /ˈsaɣðɪ/, fugl /ˈfʏɣl/, vegur /ˈvɛːɣʏr/
  • After a vowel, before j or i: becomes j (then the diphthong rules for gi apply): lagi /ˈlai̯cɪ/, segja /ˈsɛi̯ːja/
  • After a vowel, before t or s: /x/: sagt /ˈsaxt/, lagt /ˈlaxt/, saks /ˈsaxs/
  • Elsewhere: /k/: gata /ˈkaːta/, borg /ˈpɔrk/, sig /ˈsɪːk/, skóg /ˈskou̯ːk/

f, p, v

  • f is /f/ at the start of a word and /v/ elsewhere: fiskur /ˈfɪskʏr/, hafa /ˈhaːva/, afi /ˈaːvɪ/, gaf /ˈkaːv/. A doubled ff is a long /fː/: kaffi /ˈkʰafːɪ/
  • p, v before t, s, k after a vowel (p) or anywhere (v) become /f/: skipt /ˈscɪft/, hepta /ˈhɛfta/, afsakið /ˈafsacɪð/

ð and þ

Every ð is /ð/ and every þ is /θ/, with no positional variation: þakka /ˈθahka/, það /ˈθaːð/, faðir /ˈfaːðɪr/, maður /ˈmaːðʏr/, hundrað /ˈhʏntrað/.

x

At the start of a word x is /s/, elsewhere it is /xs/, and it makes the preceding stressed vowel short: vax /ˈvaxs/, taxi /ˈtʰaxsɪ/.

Nasals: ng and nk

  • ng before l or s: /ŋ/ with no g: engla /ˈɛi̯ŋla/
  • nk and other ng: /ŋk/: langur /ˈlau̯ŋkʏr/, ungur /ˈuŋkʏr/, fingur /ˈfiŋkʏr/, ganga /ˈkau̯ŋka/
  • But n + palatal k: if k has already become /c/, the n is not velarized: banki /ˈpau̯ncɪ/, lengi /ˈlɛi̯ncɪ/
  • The vowel before ng/nk changes quality (a to /au̯/, e to /ɛi̯/, o to /ɔi̯/, ö to /œy̯/, u to /u/): langur /ˈlau̯ŋkʏr/, engla /ˈɛi̯ŋla/, kongur /ˈkʰɔi̯ŋkʏr/, söngur /ˈsœy̯ŋkʏr/, ungur /ˈuŋkʏr/

Letters Outside the Icelandic Alphabet

Before anything else the module respells a few letters: c before e, é, i, í, y, ö becomes s, other c becomes k, w becomes v, y becomes i, ý becomes í, and z becomes s. Examples: Cecilía /ˈsɛːsɪlia/, Coca-Cola /ˈkʰɔːkaˌkʰɔːla/, Walter /ˈvaltɛr/, zebra /ˈsɛːpra/, kýr /ˈcʰiːr/.

Using the Tool: Practical Notes

Does the tool use a dictionary or spelling rules?

Both, in that order. A word found in the Wiktionary lexicon is shown as the dictionary gives it; any other word is transcribed by the rules, which see only letters. The lexicon is consulted by default; ?dict=false in the converter's address turns it off. See About This Tool.

Why does a compound come back with a single stress?

The rules know no component boundaries, so a compound written as one word is treated as one word: bókabúð gives /ˈpou̯ːkapuð/, with a short vowel and no secondary stress in the second part. Typing a hyphen between the components, bóka-búð /ˈpou̯ːkaˌpuːð/, supplies the boundary. Open in the converter

Does hyphenating always improve the result?

No. A hyphen before a single consonant leaves the preceding vowel short and drops the secondary stress when both parts have one syllable, so sjón-varp still gives /ˈsjou̯nvarp/. A trailing hyphen makes the module fail and the text is returned unchanged. See Stress and Compounds and Common Issues.

Can I choose a dialect or a phonetic form?

No. Icelandic has one style and one form, and regional variants are not modelled; see Phonemic vs Phonetic and Dialects & Limitations.

Implementation Details (for Developers)

The module is lua_modules/is-pron_wasm.lua (about 400 lines, a copy of the Wiktionary Icelandic pronunciation module). It is a pure Lua string pipeline: no morphological analysis, no dictionary, no phonetic second pass. The code path is:

  1. Lexicon lookup (JavaScript, scripts/utils.js): The handler in the "Lexicon Lookup with Generation Fallback" group looks the (cleaned) word up in is_lexicon.zip first (decompressed client-side, stored in IndexedDB chunks).
  2. Rule fallback: If nothing is found, window.is_ipa.toIPA(cleanText, "", "") is called.
  3. Lua pipeline (export.toIPA): respelling, left-to-right scan, three sets of rewrite rules, and cleanup, as described below.

Additional Key Processes

Lexicon Lookup

Before rule-based processing, the app checks the Wiktionary data dump (Kaikki.org). If the word is found, the dictionary entry is used as is. Only words that are missing go through the Lua module. The lexicon is consulted only for the "Phonemic" form, which is the only form for Icelandic.

The Two Empty-String Arguments

The call is toIPA(term, accent, special). The app passes "" for both optional arguments, and each has a surprising effect in the code:

  • accent is ignored. The first line of the function body is local accent = export.markAccent(term, nil), which overwrites the argument with a default array of "1" entries (one per component). Only export.show (the Wiktionary template entry point) would ever produce a custom accent array, and even that is overwritten.
  • special is meant to be a boolean. With special == true the digraph ll is output as plain /ll/ instead of /tl̥/, and rule set 2 is skipped. The app passes an empty string, which is truthy in Lua. So special == true is false (ll still becomes /tl̥/), but the check if not (special and i == 2) sees a truthy value, so rule set 2 is skipped in the app. Set 2 would delete v/ɣ after /u/; because it is skipped, múgur /ˈmuːɣʏr/ keeps its /ɣ/.

2. Component Stress (markAccent)

markAccent(term, nil) counts the hyphens and spaces in the term and returns an array with one "1" per component (so a word with no hyphen has one entry). (A custom accent string with commas is supported in markAccent but is never used in this app.) In the scan loop, whenever the current component's accent counter is 1, the module writes ˈ (first component) or ˌ (later ones) and decrements the counter. The stressed vowel is the first vowel written after the mark: the counter has reached 0 at that moment, and determineVowel receives is_stressed = (current_accent == 0).

Rule Example Input Output Description
ˈ before the first letter borg /ˈpɔrk/ Initial stress
ˌ after each "-" borgar-stjóri /ˈpɔrkarˌstjou̯ːrɪ/ Later components
"-" resets is_initial kaffi-hús /ˈkʰafːɪˌhuːs/ Aspirated forms are used again
trailing "-" is an error bóka- /bóka-/ Lua error, caught by the app; the word is returned as typed
leading "-" -bóka /ˈˌpou̯ːka/ Both marks are written

3. Left-to-Right Scan

The main while loop walks the respelled string one position at a time. At each position it tries these matchers in this order, takes the first that matches, and advances:

  1. consonant trigraph (data.trigraphs)
  2. consonant digraph (data.digraphs)
  3. the vowel digraphs au and ei
  4. single consonant (data.single)
  5. single vowel (data.vowels)
  6. hyphen (starts a new component)
  7. anything else: copied unchanged (this includes h, j, l, m, n, r, s, v, ð, digits and punctuation)

A variable is_initial is true at the start of the word and right after a hyphen, and is set to false by every other step. Table entries that hold two values use the first when is_initial is true and the second otherwise. This is why the order matters: hv is matched as a digraph before the single letter h, and au before a.

7. Vowel Quality (determineVowel)

Each vowel looks at the next two characters of the respelled term (sub(term, pos+1, pos+2)) and picks one of the three table columns of data.vowels:

  1. If the next two characters are ng or nk: column 3.
  2. Else if they are gi: column 2.
  3. Else column 1, and if the vowel is the stressed one, determineLength is applied to it.

Note that the ng/nk and gi checks apply to stressed and unstressed vowels alike, but length is only added in the third case, so a vowel before ng, nk or gi never gets the length mark.

Rule Example Input Output Description

column 2 (before gi) bogi /ˈpɔi̯cɪ/ a → ai̯, e → ei̯, o → ɔi̯, u → ʏi̯, ö → œy̯
column 3 (before ng, nk) langur /ˈlau̯ŋkʏr/ a → au̯, e → ɛi̯, o → ɔi̯, u → u, ö → œy̯

8. Vowel Length (determineLength)

For a stressed vowel in the default column, the function inspects the same two following characters (next_chars), in this order:

Rule Example Input Output Description
next_chars contains x → short vax /ˈvaxs/ x counts as two consonants
1 or 0 characters left → long þú /ˈθuː/ Word-final, or one letter left
consonant + non-consonant → long tala /ˈtʰaːla/ One consonant then a vowel. "-" does not count as a consonant, but also blocks the match
[bdgkpst] + [jrv] → long Petra /ˈpʰɛːtra/ Stop clusters that don't shorten
otherwise → short vatn /ˈvahtn̥/ Two consonants

The length mark /ː/ is appended after the whole vowel, including the nonsyllabic part, e.g., sól /ˈsou̯ːl/.

9. Rewrite Rules, Set 1

After the scan, the pieces are concatenated into one string. The module then runs three sets of regular-expression rewrites with gsub, each rule in the order written. Set 1:

Rule Example Input Output Description
(ˈ C* V) nn → tn̥ steinn /ˈstɛi̯tn̥/ After a stressed syllable only
(ˈ C* V) nn, aspirated initial kunnum /ˈkʰʏnːʏm/ The consonant class has no ʰ, so after kʰ, pʰ, tʰ the rule does not match and nn becomes a long n instead
V + g + (a, ʏ, ð, l, r) → ɣ dagur /ˈtaːɣʏr/ Fricative g
V + g + (j, i) → j segja /ˈsɛi̯ːja/ Becomes a glide (see set 3)
V + (k, g) + (t, s) → x sagt /ˈsaxt/
V + p + (t, s, k) → f skipt /ˈscɪft/
v + (t, s, k) → f afsakið /ˈafsacɪð/ f was already turned into v

10. Rewrite Rules, Set 2 (not applied in the app)

Two rules, which only run when special is falsy:

  • (u̯?ː?)[vɣ] → %1: delete a v or ɣ after /u/ (so múgur would be /muːʏr/ without the /ɣ/).
  • kʏ(ː?)ð → kvʏ%1ð: insert /v/ in kuð-.

Because the app's empty string is truthy, neither rule is applied: múgur /ˈmuːɣʏr/, kuðungur /ˈkʰʏːðuŋkʏr/.

12. Secondary-stress Cleanup

A final gsub looks for a primary part followed by a ˌ part. Syllables are counted with countSyllables (each run of vowel symbols, with an optional nonsyllabic mark and length mark, is one syllable). If both parts have exactly one syllable, the ˌ is removed.

13. Punctuation Cleanup

The last step removes full stops and commas: gsub(pron, "[%.,]", ""). Other characters pass through.

remove "." and "," ég. /ˈjɛːk/ Final full stop removed
everything else is kept 2024 /2024/ Digits are not read out

Parts of the module the app does not use

  • getRhyme: an internal function that is never called (it indexes a string as if it were a table).
  • The file ends with a test line that prints the transcription of þorn when the module loads. It has no effect on the app.

Selfoss /ˈsɛlvɔsː/ Sel-foss /ˈsɛlfɔsː/ Any f that is not word-initial is read as v; the module does not know about the component boundary Insert a hyphen
sjónvarp /ˈsjou̯nvarp/ A long first vowel (/ou̯ː/) and a secondary stress before varp Even with the hyphen (sjón-varp /ˈsjou̯nvarp/), the vowel before a consonant plus hyphen is short, and the secondary stress is dropped because both parts have one syllable No workaround in the app; check the lexicon or Wiktionary
beygja /ˈpɛi̯i̯ːja/ A single /ɛi̯ː/ followed by /j/, with no doubled glide The y becomes i, then g + j becomes jj, which the jj-rule turns into an extra glide Check Wiktionary; the same happens for beigja /ˈpɛi̯i̯ːja/
nafn /ˈnavn/ Typically a p-like stop before the n instead of a fricative (not given as IPA here) The module has no rule for f before n or l, so it reads v. Compare the respelling nabn /ˈnapn/ Report if it affects a common word; also seen in stofna /ˈstɔvna/
café /ˈkʰaːvjɛ/ Pronunciation as in the source language (not given as IPA here) Loanword spelling read as Icelandic: é is always /jɛ/ and f between vowels is /v/ Check Wiktionary
Chile /ˈkʰhɪːlɛ/ Pronunciation as in the source language (not given as IPA here) No foreign-word rules: c becomes k and h is copied Respell phonetically before transcribing
Xavier /ˈsaːvɪɛr/ Pronunciation as in the source language (not given as IPA here) Letter x at the start is always /s/; names are read as Icelandic Respell phonetically before transcribing
bóka- /bóka-/ Valid transcription of the word bóka A trailing hyphen makes the Lua code raise an error (invalid stress position) and the app returns the text unchanged Remove the trailing hyphen: bóka /ˈpou̯ːka/
-bóka /ˈˌpou̯ːka/ A single primary stress: bóka /ˈpou̯ːka/ A leading hyphen writes both a primary and a secondary stress mark Do not start a word with a hyphen
2024 /2024/ The number in words, e.g. tvö þúsund tuttugu og fjögur (the module does not expand digits) Digits are copied unchanged Spell out numbers before transcribing
